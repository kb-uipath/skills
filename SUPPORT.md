# Support

This repository is provided for reusable Codex skill development and public reference.

## Supported Use

- Installing or syncing the skill directories into a Codex skills folder.
- Running local validation with the pinned dependencies in `requirements-dev.txt`.
- Filing issues or pull requests for packaging, documentation, safety, or deterministic validation defects.

## Not Supported

- Live tenant operations, production writes, or connector changes without an explicitly authorized operator workflow.
- Customer-data recovery or secret rotation. Handle those through the owning organization, not this public repository.
- Claims that a skill is fully production certified unless the certification evidence is recorded in `docs/production-readiness-evaluation.md`.

For sensitive security reports, follow `SECURITY.md` instead of opening a public issue.
